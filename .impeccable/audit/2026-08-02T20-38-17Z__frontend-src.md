### P1 — Major

- **[P1] Text contrast below WCAG AA — RESOLVED**
  - **Location**: `frontend/src/styles/tokens.css` (dark + light blocks)
  - **Category**: Accessibility
  - **Impact**: Unreadable timestamps, chips, buttons, and links for low-vision users.
  - **WCAG**: 1.4.3 Contrast (Minimum), 4.5:1
  - **Measured fails** (computed from resolved OKLCH → linear sRGB, WCAG relative luminance):
    - Dark `--muted-2` `oklch(44%)` on bg: **2.56:1**; on surface-2: **2.18:1**
    - Dark `--accent-fg` (white) on `--accent` `oklch(64%)`: **3.36:1** (buttons, pagination active)
    - Light `--muted-2` `oklch(70%)` on bg: **2.49:1**
    - Light chips: green on green-soft **1.84:1**, red on red-soft **2.39:1**, amber on amber-soft **1.58:1**
  - **Fix applied** (verified live in Chromium):
    - Dark: `--muted-2` → `oklch(58% 0.014 260)` = **4.65:1** on bg
    - Dark: `--accent` → `oklch(55% 0.19 263)` (button fill, white text = **4.72:1**); new `--accent-link` `oklch(58%)` = **4.65:1** on bg (single accent value cannot satisfy both link-on-bg ≥4.5 and white-on-fill ≥4.5 — probe table: 57% → 4.46/4.34, 58% → 4.65/4.16)
    - Light: `--muted-2` → `oklch(55%)` = **4.51:1** on bg; chips fg → green 40% (**7.72:1**), red 52% (**4.62:1**), amber 45% (**6.24:1**); `--amber-fg` → white 99% (warn button **7.23:1**, hover **5.35:1**)
    - New dark `--red-3` `oklch(55% 0.19 25)` for `.btn.danger` = **4.72:1** (was 2.57:1 white-on-70% red); hover keeps fill + `brightness(1.06)` (transient 4.05, accepted for hover-only)
    - Nav/subnav active items + `.toast.info` text moved to `--accent-2` (**5.1:1** on accent-soft, **6.32:1** on toast bg)
  - **Residual**: dark `--muted-2` on `--surface` = 4.23:1 (large/auxiliary glyphs only); hover-state transient values — both accepted.

- **[P1] Raw Telegram HTML rendered in NotificationsView — NOT FIXED (harden pass)**
  - **Location**: `frontend/src/views/NotificationsView.vue`
  - **Category**: Implementation Integrity
  - **Impact**: Backend-provided caption content is rendered as HTML; a malformed or malicious caption could inject markup into the admin panel.
  - **Recommendation**: Sanitize or render captions as text with selective link detection.
  - **Suggested command**: `$impeccable harden`

### P2 — Minor

- **[P2] Type below 11px floor — RESOLVED**
  - **Location**: 18 rules across 15 files (BaseChip, StatusPill, StatCard, AppTopbar, AppSidebar, LoginView, DashboardView, EngineView, HistoryView, ChartsView, NotificationsView, AnalysisDetailView, global.css ×3)
  - **Category**: Accessibility
  - **Impact**: 9.5–10.5px mono labels render sub-visually; fails usability for low-vision users and makes the UI feel off-the-shelf.
  - **Fix applied**: all 9.5/10/10.5px → 11px (`global.css` `.field-label`, `.eyebrow`, `.text-xs`; `.th-sort .arr` 9px glyph → 11px). Verified: no chip/pill overflow at 11px.

- **[P2] Hard-coded colors bypass tokens**
  - **Location**: `AppToast.vue:55,57` (toast bg `oklch(23% 0.016 264 / 0.95)` + light override), `PulseIndicator.vue` (keyframe glow `oklch(74% 0.17 152 / 0.5)`), `AppSidebar.vue:265` (foot-dot border), `global.css` (select arrow `#808080`)
  - **Category**: Theming
  - **Impact**: Values won't track future token edits; theme switching needs per-theme overrides instead of a single source of truth.
  - **Recommendation**: Promote to tokens (`--toast-bg`, `--glow`, `--icon-muted`).
  - **Suggested command**: `$impeccable colorize`

- **[P2] Bounce easing on card pop-in**
  - **Location**: `tokens.css:79` `--ease-pop: cubic-bezier(0.34, 1.56, 0.64, 1)` (dashboard cards)
  - **Category**: Implementation Integrity / Performance
  - **Impact**: Dated feel; springy entrance reads as template animation.
  - **Recommendation**: Replace with ease-out-expo or remove; or keep as the single intentional accent if desired.
  - **Suggested command**: `$impeccable animate`

- **[P2] Side-tab accent borders ×2 (pre-existing, deliberate)**
  - **Location**: `DashboardView.vue:280` (scan bar, `border-left: 3px solid var(--accent)`), `EngineView.vue:230` (last-signal, `border-left: 3px solid var(--amber)`)
  - **Category**: Implementation Integrity
  - **Impact**: The most recognizable AI-UI tell; also borderline 4.1:1 accent-on-bg for the 3px bar itself (decorative).
  - **Recommendation**: Consider swapping to a subtle top/inset accent or full border; intentionally kept for hero emphasis in this pass.
  - **Suggested command**: `$impeccable quieter` / `$impeccable shape`

- **All 6 detector warnings are animation/decoration**, none structural — the structural HTML is clean (real `<button>`, `<a>`, `<th>`).
